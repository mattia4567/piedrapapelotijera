# CHANGELOG

Los cambios importantes del proyecto se registran en este archivo.

## [1.0.0] - 2026-10-14

### Agregado
- Juego de consola Piedra, Papel o Tijera contra una elección aleatoria.
- Estructura `Partida` para reunir los datos de cada partida.
- Persistencia de partidas con `ofstream` y `ios::app`.
- Consulta del historial con `ifstream`.
- Validación básica de opciones del menú y de la jugada.
- Recuperación del próximo ID a partir del historial existente.
- README, manuales y documentación inicial.
